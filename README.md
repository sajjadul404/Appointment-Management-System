## 📌 About

A **console-based Appointment Management System** built with Java to simplify appointment scheduling and management.

**Users can:**

* 📅 Book appointments
* 👀 View appointments
* ✏️ Update appointments
* ❌ Cancel appointments

---

## 🛠️ Tech Stack

* ☕ **Java**
* 📂 **File Handling**
* 🖥️ **Console Application**
